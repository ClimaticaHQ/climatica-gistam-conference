Climate science relies on large raster datasets that are rarely accessible to
non-expert users. Existing tools either require GIS expertise or offer only
static visualisations with no ability to compare locations or time periods
interactively.

This paper presents \webappname{}, a web application that provides
interactive access to  WorldClim historical climate data with the ability to 
retrieve climate statistics for a specified location but also to compare cities 
and compare climate for different time periods.

Key capabilities include both: interactive standard bars and  Walter-Lieth climatograms
with conventional arid and humid period shading, and data with plots export functionality.

Application is ready to use without any no registration 
or local software installation. It is localized in 10 languages with fast
multilingual city search.

In addition, the evaluation of the application was performed with 27 European students, whose level in
climatology was different. The System Usability Scale (SUS) score obtained 84.6 points which 
is close to excellent. The conclusion is that
\webappname{} is user-friendly app which makes it easy for everyone to visualize and explore climate data.
